## T209: simultaneous natural basepoint replacement of finite backwards-and-forwards diagram zigzags

**Lemma (proved as a model-categorical internal construction).** Let J be a finite zigzag category whose underlying undirected graph is a tree/path, with arbitrary directions on the arrows. Let I=[4]={0->1->2->3->4}. Suppose D:J×I→sSet is a strict diagram of *nonempty* simplicial sets with all J-arrows objectwise weak equivalences. Then there is a zigzag of objectwise weak equivalences of strict J×I diagrams
D -> D^fib <- E -> D^*,
where D^* admits a strictly natural section const(Δ^0)→D^*. Hence all horizontal chain arrows AND both directions of all vertical zigzag arrows in D^* strictly preserve one compatible point, and all vertical arrows remain objectwise WEs. The same holds for sampled ordinary spaces via Sing (and realization only if needed); no equivalence of WE notions in the original Top problem is changed.

**Proof.** Take an objectwise Kan replacement D→D^fib as a strict diagram. The inclusion of 0 in I is homotopy-initial for homotopy limits, so holim_(J×I) D^fib ≃ holim_J D^fib(j,0). Every zigzag edge in J induces a weak equivalence of Kan complexes at 0, and J is a contractible tree. Thus holim_J D^fib(j,0) ≃ D^fib(j0,0) for any selected vertex j0, which is nonempty. Consequently the projective-derived mapping space Map^h_(sSet^(J×I))(const Δ^0,D^fib) is nonempty. Choose a representative strict map q:Q(const Δ^0)→D^fib from a projectively cofibrant replacement Q(const Δ^0)→const Δ^0. Factor q in the projective simplicial model structure as a projective cofibration i:Q(const Δ^0)↪E followed by an objectwise trivial fibration E↠D^fib. Projective cofibrations in sSet^K are objectwise monomorphisms for this small K, as on representable cells, relative cell attachments, transfinite composition and retracts. Form the diagram pushout
D^* = E ⨿_(Q const Δ^0) const Δ^0.
This identifies the whole natural Q-section to the single terminal point in each stalk and defines a strict natural section const Δ^0→D^*. Every Q_j→Δ^0 is a weak equivalence and Q_j↪E_j is a cofibration. Left properness of sSet implies E_j→D^*_j is a weak equivalence for every j, with no requirement that E_j or original stalk arrows were monic. Hence D→D^fib←E→D^* is an objectwise-WE zigzag of *whole finite diagrams*. Two-out-of-three on every J-arrow preserves WE; all arrows preserve the indicated strict section. This uses one common J×I section, not incompatible independent vertex choices. QED.

**Limit / essential honesty.** This does NOT preserve the point-set equality of a particular original H-chain's adjacent composites under the replacement E→D^*. E may have only homotopically zero composites even where original H has literally constant doubles. The lemma repairs simultaneous based *zigzag modeling*, not a comparison of all higher nulltrack choices and certainly not the spherical typing requirement of Kochman. It cannot be used to claim that zero survives to Xu's fourfold bracket. The finite diagram's homotopy section is not an unwarranted natural strict basepoint on the original D. The absence of an arbitrary-ZIGZAG path-triviality restriction would permit monodromy obstructions; the result is explicitly for a tree.
