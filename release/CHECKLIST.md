# Explicit owner-gated release checklist

- [ ] Precise published sources with verified statements, all intended definitions and theorem labels
- [ ] Fully proved or rigorously counterexampled original result with independently attacked gaps
- [ ] First novelty audit: closest-equivalent and stronger literature
- [ ] Complete Lean kernel-checked version, frozen dependency graph, checked assumptions and cold builds
- [ ] Final distinct novelty/correctness audit including up-to-date primary citations and priority
- [ ] Owner approval and verifiable Palomar registry ID/version linking exact content
- [ ] Finished self-contained HHA manuscript, figures/data, latest journal class/style and references
- [ ] Publisher and arXiv current preprint/copyright/ethics/AI policy checked and owner approval
- [ ] arXiv ID/version confirmed after actual submission (owner-authorised)
- [ ] Editor-fit check, cover letter, author metadata, submission files, HHA EditFlow receipt (owner-authorised)
- [ ] Journal acceptance status reported **only** upon actual decision; revise according to referee record
