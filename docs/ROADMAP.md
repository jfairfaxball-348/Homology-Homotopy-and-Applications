# Roadmap and gate definitions

| Stage | Criterion for PASS | Current |
|---|---|---|
| 0. Bootstrap | Governed repo, source/claim taxonomy, protocol, journal criteria, future research prompt | PASS: administrative only |
| 1A. Candidate search | Exact catalogue of 8–12 anchored candidates, direct links, editorial fit and risk ranking | NOT STARTED |
| 1B. Research | Explicit flagship mathematical statement and serious proof/disproof attempts; verified proof or complete counterexample | NOT STARTED |
| 2. First novelty | Direct close-neighbour source audit of fixed exact theorem; record collisions and fixes | NOT STARTED |
| 3. Lean | Pinned toolchain; exact paper assumptions; fully compiling theorem and trusted kernel audit | NOT STARTED |
| 4. Final novelty | Second fresh exhaustive-where-feasible literature sweep, historical equivalences, citations, significance and no proof-gap audit | NOT STARTED |
| 5. Palomar | Owner sign-off, fixed git commit/package/check report, registry link and verification | OWNER-GATED |
| 6. Paper | Complete LaTeX paper, full independent human-readable proof, HHA fit/length/style, references | NOT STARTED |
| 7. arXiv | Owner review, current copyright/preprint compliance, category and final upload proof | OWNER-GATED |
| 8. HHA | Owner review, journal submission system and files, cover letter, submission confirmation | OWNER-GATED |

**Hard stops:** weak HHA relevance, novelty collision without substantial extension, proof dependency gap, unsound Lean workaround, or journal ethics/preprint requirement uncertainty. Maintain explicit rejected-target and counterexample logs. Finish a mathematically sound project even if the journal choice needs revisiting.
